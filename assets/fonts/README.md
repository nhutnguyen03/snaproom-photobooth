# Font local

SNAPROOM tự lưu font để không cần tải font từ CDN. Các file hiện có:

- Fraunces: `fraunces-vietnamese.ttf`, `fraunces-italic-vietnamese.ttf`
- Be Vietnam Pro: `BeVietnamPro-Regular.ttf`, `BeVietnamPro-Medium.ttf`, `BeVietnamPro-SemiBold.ttf`, `BeVietnamPro-Bold.ttf`
- JetBrains Mono: `jetbrains-mono-variable.ttf`, `jetbrains-mono-italic-variable.ttf`

Các font được phân phối theo SIL Open Font License 1.1. Giữ lại thông báo bản quyền và nội dung giấy phép trong `OFL.txt` khi sao chép hoặc phân phối các file font.
